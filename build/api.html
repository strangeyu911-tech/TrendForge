🚀 部署到公网

CloudStudio 仅托管静态文件，后端需部署到能跑 Python 的平台。选一个方案：

方案 A · Render 推荐

推送代码到 GitHub → Render 新建 Blueprint（自动识别 render.yaml）→ 填 LLM key → 2 分钟拿到公网地址。

得到：https://trendforge-api-h7n6.onrender.com/docs

方案 B · Fly.io

全球节点，香港/东京国内访问快，支持持久卷。

fly launch && fly secrets set TF_OPENAI_API_KEY=sk-xxx && fly deploy

方案 C · Docker 自托管

任意云主机，数据持久化，完全可控。

docker compose up -d   # → http://IP:8000/docs

方案 D · ngrok 临时隧道 秒开

本地已跑服务时，60 秒拿到公网地址分享给别人（电脑需开机）。

ngrok http 8000   # → https://xxxx.ngrok-free.app

完整部署指南见 src/trendforge/DEPLOYMENT.md，含 Dockerfile / render.yaml / fly.toml / docker-compose.yml
