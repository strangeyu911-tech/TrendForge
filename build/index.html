Engineering Highlights

六大技术亮点

不只是"能跑"，而是为生产环境设计的工程化系统。

01 / Agent

契约驱动 · 可插拔

5 个 Agent 通过结构化 Schema 通信，无隐式上下文。每个 Agent 可独立替换底层模型（GPT/Claude/Gemini），无状态水平扩展。

成功率 98.4% · 降级率 3.2%
02 / RAG

混合检索 · 全溯源

向量 + BM25 + 实体三路并行，RRF 融合 + reranker 重排 + 时间衰减加权。100% 片段可回溯到原始 URL。

Recall@20 ≥ 0.85 · nDCG@10 ≥ 0.70
03 / Prompt

不可变版本 · A/B 闭环

语义化版本号 + 不可变快照，每条内容可归因到确切 Prompt 版本。A/B 分桶 + 显著性检验 + 自动升版。

迭代周期 ≤ 3 天 · 实验胜出率 64%
04 / Workflow

状态机 · 熔断兜底

Temporal 持久化 + 指数退避重试 + 死信队列。失败率 >30% 自动熔断 60s，合规失败强制保守 reject + 人工。

P50 4.2 min · 人工介入率 6.7%
05 / Data

数据闭环 · 自动优化

埋点 → 数仓分层 → 看板 → 决策回流。CTR 下降触发 A/B，Bad Case 激增触发 Prompt 优化任务，全自动化。

看板刷新 T+10min · 归因覆盖 100%
06 / BadCase

分类归因 · 回归测试

7 类分类体系 + 5 Why 根因分析 + 回归测试集。每个 Bad Case 入库成为测试用例，同类复发率持续下降。
