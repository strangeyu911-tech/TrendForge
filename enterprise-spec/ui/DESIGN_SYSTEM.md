# TrendForge 控制台 · 界面设计方案（UI Design System）

> 配套 PRD v1.0 · 面向「内容运营 / 内容编辑 / 算法工程 / 数据分析」的多角色 AI 生产控制台
> 设计交付：`ui/trendforge-console.html`（可点击高保真原型，浅色/深色双主题，默认深色）
> 设计角色：UI Designer（像素君）

---

## 1. 设计目标与原则

TrendForge 把「热点发现 → 检索 → 生成 → 审核 → 发布」压缩到分钟级，使用者是**高频操作的专业运营/编辑**。界面必须同时满足：

- **密度与冷静并存**：信息密度高，但视觉要克制、可读，避免告警疲劳。
- **可信与可追溯**：每篇内容都带引用、版本、Trace，界面要让「证据」始终可见。
- **实时但不喧闹**：生产流水线、事件流是核心，但动效应服务于状态变化而非炫技。

### 设计方向（避坑通用 AI 后台蓝）

- **品牌隐喻 = 锻造/炉火**：主色用 **炉火橙 Ember**，而非 AI 套路化的「青蓝渐变 + 霓虹发光 + 默认深色发光」。
- **字体族 = IBM Plex**：`Space Grotesk`（拉丁展示）+ `IBM Plex Sans / Sans SC`（中英正文，完整中文支持）+ `IBM Plex Mono`（数据/数字），刻意避开 Inter 默认审美。
- **质感**：暖中性近黑底 + 分层表面（深色默认）；暖白 + 白表面（浅色）。统一 4px 间距体系、ease-out-quart 动效。

## 2. 设计 Token（Design Tokens）

### 2.1 色彩

| Token | 深色 | 浅色 | 用途 |
|-------|------|------|------|
| `--brand` | `#FF7A45` | `#EA5B22` | 品牌主色（炉火橙），主按钮、强调、Logo |
| `--bg` | `#161310` | `#FAF8F5` | 页面背景（暖中性） |
| `--surface-1/2/3` | `#1E1A16 / #26211B / #312A22` | `#FFF / #F6F2EC / #EDE7DD` | 卡片 / 悬浮 / 抬高 |
| `--border / --border-strong` | `#332D24 / #463C30` | `#E9E2D7 / #D8CDBC` | 描边分层 |
| `--text / --text-2 / --text-3` | `#F3EEE6 / #B6AC9C / #847A6B` | `#1C1814 / #5C5347 / #8B8071` | 主/次/弱文字 |
| `--success / --warn / --error / --info` | 绿 / 琥珀 / 红 / 蓝 | 深绿 / 深琥珀 / 深红 / 深蓝 | 语义状态 |

**角色色（每个 Agent 一套，语义清晰且彼此协调）**

| Agent | 色值（深色） | 含义 |
|-------|------|------|
| Planner | `#FF7A45` | 炉火橙 = 选题点火 |
| Research | `#2DD4BF` | 青 = 知识/检索 |
| Writer | `#F5B544` | 金 = 创作 |
| Reviewer | `#4ADE80` | 绿 = 核查通过 |
| Publisher | `#60A5FA` | 蓝 = 广播分发 |

> 对比度：正文 `--text` vs `--bg` 在双主题均 ≥ 7:1（WCAG AAA）；次要文字 ≥ 4.5:1（AA）。

### 2.2 字体阶梯

| 层级 | 字号 | 字重 | 字体 | 用法 |
|------|------|------|------|------|
| Display | 30px | 600 | Space Grotesk | 大标题 |
| H3 | 18px | 600 | Space Grotesk | 卡片标题 |
| Body | 14px | 400 | IBM Plex Sans SC | 正文 |
| Small | 12px | 500 | IBM Plex Sans SC | 标签/说明 |
| Mono | 13px | 500 | IBM Plex Mono | 指标/ID/版本号 |

### 2.3 间距与阴影

- **基准 4px**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64，用于内边距、栅格间距、组件间隙，建立稳定视觉节奏。
- **阴影**：`--shadow`（卡片）、`--shadow-lg`（浮层/弹层）；深色用低透明黑，浅色用低透明暖灰。
- **圆角**：组件 10–12px，卡片 14–16px，强调「现代但不过度圆润」。

### 2.4 动效

- 缓动统一 `cubic-bezier(.165,.84,.44,1)`（ease-out-quart）。
- 视图切换淡入上移 8px；状态变化用进度条/色块过渡；实时态用呼吸点（pulse）。
- 尊重 `prefers-reduced-motion` 时可降级（原型中实时点动画可关闭）。

## 3. App 外壳（信息架构）

```
┌─────────────┬───────────────────────────────────────┐
│  侧边栏       │  顶栏：面包屑 + 全局搜索(⌘K) + 主题切换 + 通知 + 头像 │
│  - 运营总览   ├───────────────────────────────────────┤
│  - 生产流水线  │  内容区（按角色聚合的视图，单页切换，无刷新跳转）      │
│  - 审核工作台  │                                        │
│  - Prompt实验台│                                        │
│  - Bad Case   │                                        │
│  - 设计系统    │                                        │
└─────────────┴───────────────────────────────────────┘
```

- **导航即角色动线**：内容运营看「总览 + 流水线」；编辑看「审核工作台 + Bad Case」；算法看「Prompt 实验台」；数据分析看「总览/Bad Case 数据」。
- **顶栏常驻**：实时健康态、主题切换、通知（待审数红点）、当前用户。
- **响应式**：≤980px 侧边栏抽屉化，表格/流水线降列，不隐藏关键操作。

## 5. 组件库（开发对接基线）

- **按钮**：`btn-primary`（炉火橙实底，带阴影）/ `btn-ghost`（描边）/ `btn-danger`（回退）/ `btn-sm`。
- **状态标签**：`pill` 系列（pass/fail/warn/info/brand），用于通过、拦截、修复中、观察中。
- **角色标签**：`agent-planner/research/writer/reviewer/publisher`，统一色值，全系统一致。
- **数据表**：`.tbl` 等高行、hover 高亮、mono 数字列，支持点击下钻。
- **表单**：`input` / `select` + `field` 标签，聚焦态炉火橙环 + soft 阴影。
- **进度/漏斗**：`bar` 与 `funnel`，用角色色编码阶段，一眼读懂流转。

---

## 6. 可访问性（WCAG AA+）

- 颜色对比：正文 ≥ 7:1，次要 ≥ 4.5:1；状态不只靠颜色，配图标/文字（如 ✓ / !）。
- 键盘：导航、按钮、表格行均可 Tab 聚焦，`:focus-visible` 炉火橙描边。
- 触控：交互元素 ≥ 36px（移动端按钮放大），抽屉与弹层可点遮罩关闭。
- 文本缩放：rem/流式尺寸，支持 200% 缩放不破版。
