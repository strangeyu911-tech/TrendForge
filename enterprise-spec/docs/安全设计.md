# 安全设计文档

> 配套 PRD v1.0，补齐 PRD §6「安全」非功能需求与 RAG §11 之外的系统级安全设计。

---

## 1. 范围

本设计覆盖系统级安全，聚焦：

- API 鉴权；
- 密钥管理（LLM 供应商密钥等）；
- 内部通信安全；
- Prompt 库权限；
- 数据脱敏。

---

## 2. LLM 供应商密钥

| 项 | 设计 |
|----|------|
| 存储 | KMS / Secret Manager 托管，不落业务数据库 |
| 隔离 | 按环境（dev / staging / prod）隔离，prod 密钥不出现在非生产环境 |
| 轮换 | 定期轮换，支持热切换 |
| 日志 | 密钥不进日志、不进 Trace、不进错误处理堆栈 |

---

## 3. 服务间鉴权

- 服务间调用：mTLS 或短期 Token，双向校验；
- 消息队列（Kafka）：SASL 认证 + ACL 鉴权；
- 原则：最小权限，每个服务仅持有必要权限。

---

## 4. Prompt 库权限

| 操作 | 控制 |
|------|------|
| production 版本变更 | 双人审批（编辑 + 算法），呼应 Prompt 版本管理方案 §11 |
| 审计 | 全量审计日志（变更人、时间、前后版本、审批人） |

---

## 5. 数据脱敏

- `user_id` 统一哈希后入库与关联，不存储明文用户标识（呼应 SQL 看板 §5）；
- PII（姓名、手机号、证件号等）不入库；确需使用者在隔离环境脱敏处理；
- 数据导出按最小必要原则审批。

---

## 6. 全链路 Trace 鉴权与留存

- Trace 携带调用方身份，越权调用拒绝并记录；
- 留存策略：按合规与审计要求分级留存，敏感字段在留存前脱敏；
- 访问 Trace 需权限，操作留痕。

---
