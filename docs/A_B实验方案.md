# A/B 实验方案

> 配套 PRD v1.0，定义 TrendForge A/B 实验的流程、分桶、统计与决策规则。

---

## 1. 实验目标

- 量化对比不同 Prompt 版本 / Agent 策略 / RAG 配置的效果；
- 以数据驱动迭代，避免主观偏好；
- 控制实验风险，及时止损。

---

## 2. 实验对象与维度

### 2.1 可实验对象

| 对象 | 示例变量 | 主要指标 |
|------|----------|----------|
| Writer Prompt | v1.3.0 vs v2.0.1 | CTR、阅读率、事实一致率 |
| Reviewer 严格度 | strict vs lenient | 通过率、Bad Case 率 |
| RAG 切分策略 | 段落 vs 滑窗 | 召回率、引用率 |
| RAG 融合权重 | 向量 0.7/BM25 0.3 vs 0.5/0.5 | nDCG、引用率 |
| 模板 | 快讯 vs 深度 | 完读率、互动率 |
| 模型 | gpt-4o-mini vs claude-haiku | 质量、成本、时延 |
| 发布时间 | 立即发布 vs 错峰发布 | CTR |
| 标题风格 | 信息型 vs 悬念型 | CTR |

### 2.2 实验分类

- **A/B**：单一变量两组对照（最常用）
- **A/B/n**：多变量组（如模型选型 4 组）
- **MVT**：多变量正交实验（少用，样本需求大）

---

## 3. 实验流程

```
1. 假设设计 ─► 2. 样本量计算 ─► 3. 分桶配置 ─► 4. 灰度运行
                                                          │
                                                          ▼
5. 决策 ◄─ 4. 显著性检验 ◄─ 3. 数据采集 ◄─ 2. 上线实验
```

### 3.1 假设设计

每个实验必须有可证伪的假设：

> **示例**：假设 Writer Prompt v2.0.1（增加"开头 50 字内必须出现核心事实"约束）相比 v1.3.0，能提升财经类内容 CTR ≥ 10%，且不降低事实一致率。

- 原假设 H0：v2.0.1 的 CTR ≤ v1.3.0
- 备择假设 H1：v2.0.1 的 CTR > v1.3.0 × 1.10
- 显著性水平 α = 0.05
- 检验功效 1-β = 0.8

### 3.2 样本量计算

**比例指标（CTR）**：

```
n = (Z_{α/2} + Z_β)^2 * [p1(1-p1) + p2(1-p2)] / (p2-p1)^2
```

示例：基线 CTR p1=0.04，期望 p2=0.044（+10%），α=0.05，β=0.2：

```
n ≈ (1.96+0.84)^2 * [0.04*0.96 + 0.044*0.956] / (0.004)^2
  ≈ 7.84 * 0.0796 / 0.000016
  ≈ 39,000 per group
```

每篇内容需 ≥ 39,000 曝光/组，按单篇 1000 曝光估算，每组需 ~40 篇内容。

**连续指标（阅读率）**：用两样本 t 检验样本量公式。

### 3.3 分桶策略

- 分桶单元：`content_id` 哈希 → 0-99 桶；
- 同一实验内分桶互斥；
- 不同实验可正交（互不影响）；
- 分桶比例可在运行时调整，无需重启；
- 分桶日志实时写入 `experiment_assignments`。

```python
def assign_bucket(content_id: str, experiment_id: str, splits: dict) -> str:
    h = md5(f"{experiment_id}:{content_id}".encode()).hexdigest()
    bucket = int(h[:8], 16) % 100
    cumulative = 0
    for variant, ratio in splits.items():
        cumulative += int(ratio * 100)
        if bucket < cumulative:
            return variant
```

### 3.4 灰度策略

```
阶段1：5% treatment，1h 观察 → 无异常
阶段2：10% treatment，4h 观察 → CTR 无明显劣化
阶段3：50% treatment，2 天 → 显著性达标
阶段4：100% treatment（升版）
```

任意阶段出现 Bad Case 激增或 CTR 显著下降 → 熔断回滚。

## 4. 指标体系

### 4.1 核心指标（决策依据）

| 指标 | 定义 | 目标方向 |
|------|------|----------|
| CTR | clicks / impressions | ↑ |
| 阅读率 | reads / clicks | ↑ |
| 完读率 | finishes / reads | ↑ |
| 事实一致率 | 一致 claims / 总 claims | ↑ ≥ 98% |
| Bad Case 率 | bad_case / total | ↓ |

### 4.2 护栏指标（不可恶化）

| 指标 | 阈值 |
|------|------|
| 事实一致率 | ≥ 95% |
| 合规违规数 | = 0 |
| 单条成本 | ≤ ¥0.8 |
| 生产时延 P95 | ≤ 15 min |

护栏指标恶化即熔断，不看核心指标。

### 4.3 辅助指标（解释用）

- 互动率、分享率
- 平均阅读时长
- 引用覆盖率
- Token 消耗

---

## 5. 统计检验

### 5.1 检验方法选择

| 指标类型 | 分布 | 检验方法 |
|----------|------|----------|
| CTR（比例） | 二项 | Z-test / 卡方 |
| 阅读率（比例） | 二项 | Z-test |
| 完读率（比例） | 二项 | Z-test |
| 阅读时长（连续） | 偏态 | Welch t-test（log 变换）或 Mann-Whitney U |
| 质量分（连续） | 近似正态 | Welch t-test |
| Bad Case 率（比例，低发） | 稀疏 | Fisher 精确检验 |

### 5.2 多重比较校正

- 单实验多指标：Bonferroni 校正（α/m）；
- 多实验并行：控制实验互斥，避免污染。

### 5.3 显著性判定

- p < 0.05 且效应量达到预设 MDE（最小可检测效应）；
- 护栏指标无恶化；
- 样本量达标；
- 实验时长 ≥ 7 天（覆盖周内周期）。

### 5.4 常见陷阱规避

| 陷阱 | 规避 |
|------|------|
| 偷看（peeking） | 用序贯检验或固定时长后再看 |
| 幸存者偏差 | 分桶在内容级，不是用户级时注意 |
| 辛普森悖论 | 分品类看，再汇总 |
| 新鲜效应 | 实验至少 7 天 |
| 泄漏 | 分桶日志与指标 join 时去重 |

---

## 6. 决策规则

| 核心指标 | 护栏 | 决策 |
|----------|------|------|
| treatment 显著优于 control | 无恶化 | ✅ 升版 production |
| treatment 显著劣于 control | - | ❌ 终止，回炉 |
| 无显著差异 | 无恶化 | ⏸ 延长 3 天；仍无差异保留 control |
| - | 护栏恶化 | 🛑 熔断回滚，不计核心指标 |
| Bad Case 激增 | - | 🛑 熔断 |

## 7. 实验报告模板

```markdown
# 实验报告：exp_writer_v2_vs_v1

## 1. 背景
v1.3.0 财经类内容 CTR 7 日均值 0.038，低于目标 0.05。假设 v2.0.1 增加"开头强事实"约束可提升 CTR。

## 2. 实验设计
- 对象：Writer Prompt
- 变体：control=v1.3.0, treatment=v2.0.1
- 分桶：50/50，content_id 哈希
- 时长：7 天（2026-07-14 ~ 2026-07-20）
- 样本：control 412 篇 / treatment 408 篇

## 3. 结果
| 指标 | control | treatment | 差异 | p-value | 显著 |
|------|---------|-----------|------|---------|------|
| CTR | 0.038 | 0.044 | +15.8% | 0.012 | ✅ |
| 阅读率 | 0.62 | 0.65 | +4.8% | 0.08 | ❌ |
| 完读率 | 0.41 | 0.43 | +4.9% | 0.11 | ❌ |
| 事实一致率 | 0.978 | 0.981 | +0.3% | 0.45 | ❌ |
| Bad Case 率 | 0.044 | 0.029 | -34.1% | 0.03 | ✅ |
| 单条成本 | ¥0.31 | ¥0.33 | +6.5% | - | 护栏内 |

## 4. 结论
treatment 在 CTR 与 Bad Case 率上显著优于 control，护栏指标无恶化。
**决策：v2.0.1 升版 production，v1.3.0 archived。**

## 5. 后续
- 观察 7 天确认无回归；
- 复盘 v2.0.1 有效因素，沉淀到 Prompt 最佳实践。
```

## 9. 实验文化

- 鼓励小步快跑，每周 ≥ 2 个实验；
- 失败实验同样有价值（排除错误方向）；
- 实验结论必须归档，避免重复踩坑；
- 季度实验复盘会，沉淀方法论。
