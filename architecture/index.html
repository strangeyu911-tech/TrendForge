Agent 协作链路 & I/O 契约

Agent 降级策略 失败兜底 Planner 规则打分替代 LLM 24h 缓存选题 Research 单源降级(RAG或Web) 人工补充线索 Writer 草稿模型+精修 转人工 Reviewer 规则评分替代 LLM 强制 reject + 人工 Publisher 单渠道隔离 撤回 + 人工 全部失败 → 死信队列 → 告警人工 · 熔断：失败率>30% 熔断 60s 重试：指数退避 5s→10s→20s，最多 3 次 · 人工介入：高危话题强制
Happy Path 时序（P50 ≈ 4 分钟） T+0s Planner 选题 +30s Research 检索 +90s Writer 生成 +180s Reviewer 审核 pass +240s Publisher 灰度发布 → 30min 观察全量

RAG 新闻知识库架构

新闻源接入 ≥10 个，可信度分 4 级（央媒 1.0 → 自媒体 0.3）。增量入库 Kafka→Flink→向量库，延迟 ≤5 min。冷启动回灌 30 天数据约 50 万文档。

Workflow 状态机 & DAG 编排

数据闭环：生产 → 分发 → 优化

数据 T+10 min 刷新看板。每条发布内容携带 prompt_version/trace_id，回流时按版本聚合归因。Bad Case 触发 Prompt 优化任务，CTR 下降触发 A/B 实验，形成自动化优化闭环。
